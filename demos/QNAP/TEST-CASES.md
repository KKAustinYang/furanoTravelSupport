# チケットデモ 検証用テストケース

`tickets.html` のフォームから GPTBots の Agent（QNAP サポートAI アシスタント）へ投げるための
テスト集。**すべて実チケット12件のナレッジベースに対応**していて、どの回答がどのチケットに
着地すべきかを書いてある。商談前の動作確認と、精度のリグレッション確認の両方に使える。

見方:

- **入力** … フォームにそのまま貼る値。`説明` は日本語のまま貼れる
- **期待** … 根拠にすべきチケットと、回答に含まれるべき要点
- **NG** … これが出たら要調整（ナレッジ未ヒット or ハルシネーション）

---

## A. 基本 — ナレッジに直撃する6件

### A-1. スマートバージョン管理の週数（最頻出）

| 項目 | 値 |
|---|---|
| シリアル / モデル / FW | SN-manual / 6B100-ABP301 / QTS 5.2.x |
| カテゴリー | バックアップ・同期 → HBS 3（Hybrid Backup Sync） → 設定方法を知りたい |
| 件名 | スマートバージョン管理の週数設定について |

```
2台で相互バックアップを取り、日次7・週次4・月次12で1年分を保持したいです。
週数が4だと、月の後半など取得できない週が発生しませんか。5にすべきでしょうか。
またバックアップは差分になりますか。
```

- **期待**（Q-202602-10403）: ①週数4でも空白週は出ない（カレンダー週ではなく**ローリング方式**）②5にすると1世代増えて容量を消費するだけ ③初回フル以降は**差分（増分）**、復元時は自動統合
- **NG**: 「5に設定すべき」と断定する／差分かフルかを答えない

### A-2. データ圧縮の項目が出ない

| 項目 | 値 |
|---|---|
| カテゴリー | バックアップ・同期 → HBS 3 → 想定どおりに動作しない |
| 件名 | HBS3に「データ圧縮を使用する」が表示されない |

```
TS-453E（Celeron J6412）でバックアップジョブを作成していますが、詳細設定に
「データ圧縮を使用する」が表示されません。QuDedupの項目は出ています。
x86モデルなのに表示されないのはなぜですか。
```

- **期待**（Q-202602-11258）: 「データ圧縮（bzip）」は**クラウドバックアップジョブ限定**。ローカル／リモートNAS宛では表示されない。圧縮・QuDedupは**x86のみ**（ARM非対応）で、TS-453EはQuDedup利用可
- **NG**: CPU非対応が原因だと誤答する（このモデルはx86）

### A-3. 別拠点からアクセスできない

| 項目 | 値 |
|---|---|
| カテゴリー | ネットワーク・接続 → 共有フォルダへの接続 → エラーが表示される |
| 件名 | 別拠点のTS-264にアクセスできない |

```
別拠点のQNAP（TS-264）に共有フォルダもQfinder Proでもアクセスできません。
同一拠点内からはアクセスできます。別拠点からはpingも応答がありません。
同じ拠点のTS-262（QuFirewallなし）にはアクセスできています。
```

- **期待**（Q-202603-15122）: **QuFirewall が自拠点セグメントのみ許可**している可能性。まず一時無効化して切り分け → 別拠点セグメントを許可ルールに追加
- **NG**: VPNやルーティングだけを疑ってファイアウォールに触れない

### A-4. 長いファイル名が保存できない

| 項目 | 値 |
|---|---|
| カテゴリー | ストレージ・ディスク → ストレージプール → 想定どおりに動作しない |
| 件名 | 85文字を超えるファイル名の保存に失敗する |

```
Windows Serverの共有からQuTS heroの共有フォルダへコピーすると、長いファイル名が
保存できません。ZFSのlongnameを有効化できますか。SMB利用時のフルパス上限も知りたいです。
```

- **期待**（Q-202604-19890）: 原因は**Windowsエクスプローラーの MAX_PATH（260文字、実質約244）**。ZFS longname は**有効化不可・サポート対象外**。ZFS側のフルパス上限は日本語で約4000文字弱なので十分長い。回避策は階層短縮 / Robocopy
- **NG**: NAS側の制限が原因だと結論づける

### A-5. スナップショットの保持設計

| 項目 | 値 |
|---|---|
| カテゴリー | バックアップ・同期 → スナップショット → 設定方法を知りたい |
| 件名 | 7日分のスナップショット保持のベストプラクティス |

```
8時から20時まで1時間ごとにスナップショットを取得し、7日分を保持したいです。
スマートバージョン管理は「12毎時／7日次／1毎週／1毎月」に設定すべきでしょうか。
```

- **期待**（Q-202605-28459）: 単純な間隔保持なら**スマートバージョン管理は使わず**、シンプルなスケジュール＋**保存ポリシー1週間**が最適
- **NG**: スマートバージョン管理の設定値を細かくいじる方向で回答する

### A-6. RAIDのスロット順

| 項目 | 値 |
|---|---|
| カテゴリー | ストレージ・ディスク → RAID → 設定方法を知りたい |
| 件名 | スペアディスク使用後にスロット順を戻したい |

```
4ベイでスペアを設定していました。HDD1が故障してスペアのHDD3が使われ、いまは
HDD2とHDD3で動いています。HDD3をHDD1のスロットに戻したいのですが手順を教えてください。
```

- **期待**（Q-202606-34123）: RAIDは**ソフトウェア制御でスロット順は無関係**。移したい場合は**シャットダウンしてから物理的に入替**、設定変更は不要
- **NG**: RAID再構築やボリューム再作成を案内する

## B. マルチターン — 返信で文脈が続くかを見る

会話IDを引き継いでいるので、**前の回答を踏まえた応答**になるかを確認する。

### B-1. 切り分け → 恒久対応（A-3の続き）

1回目に A-3 を投げてから、返信欄に:

```
QuFirewallを無効化したところ、別拠点からpingが通るようになりました。
セキュリティは維持したいので、無効のままにはしたくありません。次にやるべき設定を教えてください。
```

- **期待**: 原因確定を受けて、**別拠点セグメントの許可ルール追加**へ進む（プロファイル編集 → ルール追加）
- さらに追撃:

```
ルールを追加して適用を押したのですが、確定の「はい」ボタンが表示されず保存できません。
```

- **期待**（同チケット後半）: **ブラウザをCtrl＋スクロールで縮小**すると保存ボタンが出る

### B-2. 容量の不安（A-1の続き）

```
48TBのうち10TBをデータ領域、38TBをバックアップ領域にする予定です。
日次7・週次4・月次12で1年分を保持した場合、容量は足りますか。
```

- **期待**: 差分方式のため毎回フルではないが、**更新頻度・変更量で増加**するため余裕を持った運用を推奨、という趣旨（断定的な容量計算を捏造しないこと）
- **NG**: 「◯TBで足ります」と根拠なく断言する

### B-3. 前提を変える

A-5 のあと:

```
やはり1時間ごとではなく30分ごとに変更し、保持は3日にしたいです。設定はどう変わりますか。
```

- **期待**: 前回の設計を引き継いだうえで、スケジュール間隔と保存ポリシーの変更点だけを answer する

## C. 添付ファイル — 中身を読んでいるかを見る

### C-1. エラー画面の画像

A-3 と同じ内容で、**画像を1枚添付**（例: ファイアウォールのブロック表示、pingのtimeout画面。文字が読める画像であること）

- **期待**: 回答の中で**画像内の文字列やIP/セグメントに言及**する
- **NG**: 添付に一切触れない（＝読めていない）

### C-2. ログの表（csv / xlsx）

```
時刻,送信元,結果
10:01,10.20.0.5,timeout
10:02,10.20.0.5,timeout
```

上記を `ping_log.csv` として添付し、説明に「別拠点からのping結果を添付します」と書く。

- **期待**: 表の中身（timeoutが継続している、送信元セグメント）に触れて切り分けに使う
- **注意**: `.doc` / `.xls` は Agent 側が非対応。`.docx` / `.xlsx` で試すこと

## E. 境界・ネガティブ — 「知らないことを知らないと言えるか」

### E-1. ナレッジ範囲外（転送されるべき）

| カテゴリー | アカウント・権限 → ライセンス → 設定方法を知りたい |

```
QNAP NASをKubernetesの永続ストレージ（CSIドライバ）として使い、ArgoCDのGitOpsと
連携させたいです。推奨構成とマニフェスト例を教えてください。
```

- **期待**: **確信が持てない旨を明示**し、担当者へのエスカレーションを提案する
- **NG**: それらしいマニフェストを創作する（＝最も危険なハルシネーション）

### E-2. 情報不足（逆質問すべき）

```
NASが遅いです。どうすればいいですか。
```

- **期待**: モデル・症状の発生条件・プロトコル（SMB/AFP）・時間帯などを**確認する質問を返す**
- **NG**: 一般論のチューニング手順を長々と並べる

### E-3. 事実に無い型番

```
TS-999XX でスマートバージョン管理を使いたいのですが、対応していますか。
```

- **期待**: 型番を確認できない旨を伝え、断定しない
- **NG**: 存在しない型番の仕様を語り出す

### E-4. 分類と本文が矛盾（構造化の効き目）

| カテゴリー | ストレージ・ディスク → RAID → エラーが表示される |
| 件名 | RAIDのエラーについて |

```
（本文はまったく別の話題）iPhoneのQfile Proで、レコーダーからコピーした地デジ録画が
一覧に表示されません。視聴できるアプリはありますか。
```

- **期待**（Q-202604-20583）: 分類に引きずられず**本文の内容（DTCP）で回答**する。DTCPの著作権保護によりQfile/SMB経由では再生不可、sMedio TV Suite のiOS版はサポート終了、レコーダー各社のアプリを確認
- **NG**: RAIDの話を始める

## F. その他のナレッジ確認（余裕があれば）

| # | 投げる内容（説明欄） | 期待（根拠） |
|---|---|---|
| F-1 | 「App Center で『最新アプリの更新情報をオンラインで取得できません』という通知が届きます。原因と手動更新の手順を教えてください」 | ネット未接続 or FWブロックが原因、手動インストール手順を案内（Q-202603-13959） |
| F-2 | 「QuMagieで写真を振り分けている最中に、勝手にログアウトされます」 | **2.8.2へ更新**＋個人設定の**アイドル自動ログアウトを無効化**（Q-202603-14322） |
| F-3 | 「Amazonで買ったTS-464eU-8G-US（QFKN4172594）が故障。販売元が分かりませんが修理できますか」 | 保証期間内なら販売元不明でも**直接RMA可・無償**。US並行輸入品は**台湾本社へ直送**、送料は片道ずつ負担（Q-202605-29477） |
| F-4 | 「MacでNASに繋ぐと Multimedia / Public / Video が別ボリュームで出ます。任意の1つにまとめられますか」 | まとめるのは**不可**。Publicは削除不可の自動作成、MultimediaはMultimedia console導入時に自動作成、Videoはユーザー作成なら削除可（Q-202606-33349） |
| F-5 | 「NAS側をローカル、Box側をホストとしてリアルタイム同期したい。HybridMountとHBSどちらですか」 | HybridMountはキャッシュ経由で**リアルタイムではない**。**HBS**なら双方向/一方向のリアルタイム同期可。双方向は競合に注意し、Box主・NAS参照を推奨（Q-202602-11708） |

## 判定の目安

| 観点 | OK | 要調整 |
|---|---|---|
| 根拠 | 実チケット番号や公式FAQに触れる | 出典に一切触れない |
| 粒度 | まず1ステップの切り分けを提示 | 手順を10個並べて丸投げ |
| 敬語 | 日本のサポート敬語 | 機械翻訳調 |
| 不明時 | 確信がない旨＋有人へ | それらしく創作する |
| 添付 | 画像/表の中身に言及 | 添付を無視 |

## 既知のギャップ（デモ前に確認）

フォームの `問題のカテゴリー` は現在 **4分類**（バックアップ・同期／ストレージ・ディスク／
ネットワーク・接続／アカウント・権限）しかないため、ナレッジにある次の話題は
**分類を選べない**（本文には書けるので回答自体は返る）。

- マルチメディア・アプリ（QuMagie、DTCP録画）… F-2 / E-4
- 保証・RMA … F-3
- システム通知・アップデート（App Center）… F-1

商談で E-4 / F-1〜F-3 を見せる場合は、選択肢を足しておくと自然。追加案:

```
問題のカテゴリー: ＋ マルチメディア・アプリ ／ 保証・RMA ／ システム通知・アップデート
サブカテゴリー  : マルチメディア・アプリ → QuMagie / Multimedia Console / DTCP録画
                  保証・RMA           → 保証状況の確認 / 修理依頼 / 交換
                  システム通知         → App Center / ファームウェア更新 / アラート通知
```
