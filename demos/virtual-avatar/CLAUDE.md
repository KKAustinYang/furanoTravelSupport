# バーチャルアバター デモ（開発ガイド）

不動産の物件紹介を、**アバターが喋る紹介動画**として自動生成するデモ。
最終形は「台本 → ナレーション音声 → アバター動画」だが、**まずナレーション生成だけを
切り出して検証している**（この工程が一番壊れやすいため）。

- 実装: `tools/narrate.py`（単体で動く Python CLI・ビルド不要）
- 公開ページ: **未実装**。`index.html` が無いので `build-demos.mjs` はこのフォルダを
  スキップする（`⚠ skip` が出るのは想定どおり）
- 使用モデル: Modellix `alibaba/cosyvoice-clone`（音声）／`google/gemini-3.5-transcribe`（検証）

---

## 1. なぜ分割合成なのか（設計の根幹・変更前に必読）

LLM ベースの TTS には既知の失敗モードがある。**スキップ**（長い入力の途中を丸ごと
飛ばす）と**リピート**（同じ箇所を繰り返す）。実測では 126 文字を1回で投げたところ、
中間の 61 文字が消えて 10.6 秒（本来 約22秒）で返ってきた。

対策は「台本を約5秒ずつのチャンクに割り、個別に合成して結合する」。
短い入力ならスキップは起きにくい。特定モデルの欠陥への対症療法ではなく、
長尺 TTS における一般的な推奨実装（Google の Gemini TTS でも chunking が推奨されている）。

**秒で機械的に切ってはいけない。** 合成前に長さは分からないし、文の途中で切ると
抑揚が壊れる。文・節の境界を守りながら、5秒相当の拍数に近づけてパックする。

## 2. 実測でわかったこと（2026-09-02）

### instruction を渡してはいけない

自由文の `instruction` を渡すと、モデルが**指示文を読み上げたうえで本文を2回繰り返す**。
ASR で確認済み。詳細と実測表は `tools/README.md`。既定では空にしてある。

口調を変えたいときは参照音声を録り直す。`instruction` を復活させないこと。

### enable_preprocess は出力長に影響しない

instruction の有無だけで結果が決まった（同 seed で完全一致）。
同じ seed なら再現するので、**seed を変えて引き直すリトライは有効**。

### 長さの見積もりは「文字数」ではなく「拍数」

`2LDK` は4文字だが「ツーエルディーケー」で9拍。素の `len()` で見積もると短く外れ、
スキップと誤判定して無駄に引き直す。`weighted_chars()` で半角英数を 2.2 拍として数える。

## 3. 検証済みの受け入れ基準（仕様書 §13）

| 項目 | 結果 |
|---|---|
| `--dry-run` が API を呼ばずに分割結果を表示 | ✅ 149文字 → 6チャンク・予測26.1秒 |
| 文・節の境界で切れている | ✅ 単語の途中で切れたチャンクなし |
| タグ境界をまたいで結合しない | ✅ `[AVATAR]` / `[FOOTAGE:*]` で分離 |
| チャンクを個別生成し `output/parts/` に残す | ✅ |
| 長さを検証し、乖離が大きければ引き直す | ✅ instruction 起因の2倍長を検出・再生成 |
| `report.json` に予測/実測/乖離/ギャップを記録 | ✅ |
| 「。」の後のギャップ ＞ 「、」の後のギャップ | ✅ 重み 1.0 : 0.4 |
| 出力が目標 ±0.5 秒以内 | ✅ **30.00 秒**（目標 30.0） |
| 台本の過不足を文字数で警告 | ✅ 「約16文字短くしてください」 |
| 1文だけ直すと影響チャンクだけ再生成 | ✅ 7チャンク中4チャンクをキャッシュから再利用 |
| API キーがコード・設定に無い | ✅ `MODELLIX_API_KEY` のみ |
| `--compare` が複数モデルを別ファイルに出す | ✅ minimax も動作（乖離 2〜16%） |

## 4. これからやること

1. **アバター動画の生成**：`kling/kling-avatar`（ポートレート＋音声 → リップシンク動画）
   または `pixverse/lipsync`。`output/parts/00N.mp3` をタグ区間ごとに渡せば、
   顔出し区間と物件映像区間を切り替えた動画にできる
2. **デモページ（`index.html`）**：他の静的デモと同じ単一HTML。台本を入れて
   秒数を指定 → 音声とアバター動画が出るところまで見せる
3. 参照音声のアップロード導線（いまは公開URLを手で渡している）

## 5. 触るときの注意

- `instruction` を config に戻さない（2章）
- `ja_chars_per_sec` を変えるとチャンクの切れ目も変わり、キャッシュが効かなくなる
- `output/parts/` は後工程で使うので消さない
- 課金は1チャンク約 $0.001。リトライを惜しむ必要はない
